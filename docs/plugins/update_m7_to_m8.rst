Update Plugins for Mautic 8
###########################

Mautic 8 includes breaking changes that affect Plugins and Integrations. The :xref:`UPGRADE_GUIDE_8` in the Mautic repository describes the breaking changes and how to update your code. The Mautic team keeps that file up to date, so use it as the checklist for upgrading your Plugin.

.. tip::

   The upgrade guide is a single Markdown file, so you can give it to an AI coding agent together with your Plugin's code to help with the upgrade.

To learn how to build a Plugin, start with :ref:`Plugins/getting_started:Getting started with Plugins`.
